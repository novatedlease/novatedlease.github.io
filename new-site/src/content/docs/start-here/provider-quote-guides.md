# Find calculator figures on your provider's quote

Choose a provider to see the labels and sections used on a quote layout we reviewed. Each page maps those labels to the fields in [Guided mode](/calculator/).

- [SG Fleet quote guide](/start-here/how-to-read-sgfleet-quote/)
- [Smart Leasing quote guide](/start-here/how-to-read-smartleasing-quote/)
- [Maxxia quote guide](/start-here/how-to-read-maxxia-quote/)
- [Paywise quote guide](/start-here/how-to-read-paywise-quote/)
- [Smartsalary / Smart Drive quote guide](/start-here/how-to-read-smartsalary-quote/)

The illustrations are original **schematics with labels only**. They contain no customer's quote, vehicle details, dates, identifying details or amounts. Provider layouts change, so check the headings and footnotes on your own quote. If a label differs, use the [general quote guide](/start-here/how-to-read-a-novated-lease-quote/) and the hints inside Guided mode.

The provider picker in Guided mode also gives short instructions beside the relevant field for other providers. You can skip it if yours is not listed.
